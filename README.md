## Deskripsi
- Soal 1: komponen `InfoCard` yang dapat dipakai ulang, dengan props `title`, `status`, dan `onPress`, serta badge berwarna sesuai status.

## Cara Menjalankan

```bash
npm install
npx expo start 
# atau:
npx expo start --tunnel
```
